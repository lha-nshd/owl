Applying for NSHD data

Prefer a picture? See the process diagrams.

How do I apply for NSHD data?

Read How Applications Are Reviewed and Apply for Data to understand the process, then submit the Data Access Request Form.

How long does it take to receive NSHD data?

Data are typically received within a month. The process at a glance explains each step.

What documents do I need to provide in support of my application?

The required documents are listed under Access Prerequisites. Do not attach them to your application. NSHD requests them at the appropriate stage through an automated sequence of emails, so you only need to submit the request first.

I want my students to analyse NSHD data for my project. Do I need to list them as co-applicants?

Yes. Everyone who uses NSHD data must be named, provide a completed and signed confidentiality form, and provide a valid data security awareness training certificate. You will be told when these are needed. If you have not yet chosen student names you can still apply, because additional users can be added at any time, including after your project data have been provided.

Changes to an approved project

How do I add an additional user to my approved project?

Complete the Additional Users / Data Request form.

How do I request additional NSHD data (a new basket) for my approved project?

Submit the same Additional Users / Data Request form to request an additional basket.

I did not add a basket ID to my application, which is now approved. How can I tell you what data I want?

Provide your basket ID through the Additional Users / Data Request form.

For projects approved before 1 January 2023, do not use the form. Email mrclha.swiftinfo@ucl.ac.uk instead.

After approval

How do I request outputs, such as tables and figures, from the Data Safe Haven?

Complete the DSH Output Request form. See After Approval for more.

My project is due to expire. How do I request an extension?

Complete the Project Extension Request form and email it to mrclha.swiftinfo@ucl.ac.uk, before the project's original end date has passed.
