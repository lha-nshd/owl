The NSHD data sharing infrastructure is made up of three complementary platforms. OWL is where you discover and explore variables — searching the data dictionary in a range of ways, reading questionnaires and topic pages, and reviewing variable-level metadata. Condor is where you build and save your basket of variables for a data request. Skylark holds the data access information, prerequisites, and forms needed to make a formal application.

OWL — Variable Discovery & Documentation

You are here. The OWL (Online Wellbeing and Lifecourse Resource) is the starting point for any data request. Use it to:

  • Find variables in seven different ways — from keyword search and browsing by category to the UK LLC Catalogue and Discover Projects — across 28,000+ variables (see About the Searches)
  • Browse variables by topic category — Clinical data, Questionnaire data, and more — navigating a hierarchical category tree
  • Read questionnaire instruments from 1946 to the present day, with variables annotated directly on the source documents
  • Explore topic pages covering physical health, cognition, mental health, social circumstances, biological samples, and more
  • Review variable-level metadata including the questionnaire form, question number, year of collection, derived status, value labels, and frequency distributions
  • Build a basket of variables and export it as a pre-filled data dictionary, ready for a formal data request via Condor
  • Upload a basket file back into OWL — either one you downloaded earlier or a copy of the data dictionary marked up yourself — to resume where you left off or add a batch of variables at once
  • See how NSHD data is being shared on the Metrics and Trends page — applications per year, where requests come from, approval times and the most requested variables
  • Search topsheets, variable notes and data notes in one place with Search Documentation, and add variables to your basket directly from a documentation page
  • Create your own documentation online with Create Documentation Online (Doc Builder) — build a topsheet in the browser with a live preview and download it as a Word document, with Page Proof available to check formatting offline
  • Upload the basket to Condor for finalising before making for a formal data request
No login is required to use OWL. All variable metadata, questionnaires, and topic pages are publicly accessible.

Condor — Variable Basket & Data Request Platform

Condor is the NSHD data sharing platform and holds around 35,000 variables. It is the system through which baskets of variables are created by users with a unique basket ID. Once you have identified the variables you need using OWL, use Condor to:

  • Get access to all of the variables available for data sharing, even those not yet cleaned in the metadata emhancement project
  • Create basket(s) of variables by searching and selecting within Condor, or by importing a list of variable names from your OWL export
  • Make use of the basket management tools: editing or sharing your basket with other researchers
  • Save the basket to get a basket ID, which you then submit with your data access request on Skylark
  • Request additional variables for an already-approved project
  • Users must register for an account and be formally approved as a bonefide researcher

All user accounts and baskets have been migrated from the previous systems (Skylark/Swift). If you are a new user you will need to register before building a basket.

Skylark — Data Access Information & Forms

Skylark is the NSHD data access information and forms portal. Questionnaire instruments and topic pages have moved to OWL — Skylark is now referenced for data access purposes only. Use Skylark for:

  • Data Access Request Form — the primary form for submitting a new data request
  • Additional Users / Data Request form — for adding users or requesting further variables on an approved project
  • DSH Output Request — for releasing outputs from the UCL Data Safe Haven portal
  • Project Extension Request — for extending the duration of an approved project
  • Data sharing process — step-by-step guidance on how NSHD data access works, including the review and approval process
  • Access prerequisites — the training courses and agreements that must be completed before data access can be granted
  • FAQs — frequently asked questions about the application process, eligibility, and data governance
Skylark is at skylark.ucl.ac.uk/NSHD

Variable Metadata Pages

Every variable on OWL and Condor has a dedicated metadata page presenting the same information on both platforms — questionnaire provenance, linked longitudinal variables, category memberships, value labels, and frequency distributions. OWL also lets you compare a variable across sweeps: a “View all sweeps” button on any variable that's part of a Truly Longitudinal group opens every sweep's distribution together on one page, with a merged statistics table.

UK LLC — Linked Data Access Route

Alongside Condor and Skylark, NSHD data can also be accessed via the UK Longitudinal Linkage Collaboration (UK LLC) — a national Trusted Research Environment that links NSHD data to more than 20 other UK longitudinal studies, plus NHS, education and other administrative records. NSHD datasets are deposited into UK LLC continuously, so this is the route to use when your research needs NSHD variables analysed alongside other cohorts or linked records, rather than NSHD data on its own.

Typical journey from discovery to data

Most data requests follow the same sequence of steps across the three platforms:

1

Explore on OWL

Use any of the OWL searches, read questionnaires and topic pages. Build a basket of candidate variables and export it as an Excel file. Review the NSHD Metadata page for each variable to understand its provenance, coding, and any caveats.

2

Build and save your basket in Condor

Register on Condor if you are a new user. Build or import your basket of variables and save it to get a basket ID. A basket can contain more than 500 variables: Condor automatically splits larger baskets into baskets of 500 when you save. They are still treated as a single basket for your request, so a larger basket may take longer to turn around because of the risk assessment.

3

Complete prerequisites via Skylark

Complete the required access prerequisites — training courses and data governance agreements — then submit the Data Access Request Form on Skylark, quoting your Condor basket ID. The Skylark data sharing process pages explain what is required and in what order.

4

Receive and release data

Once approved, data is accessed through the UCL Data Safe Haven. When your analysis is complete, submit a DSH Output Request via Skylark to release outputs from the secure environment.
